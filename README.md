## About Me

I'm a frontend developer who believes great web experiences start with a solid understanding of **HTML, CSS, and JavaScript** — the true foundation of the web. Frameworks come and go, but the fundamentals always remain.

Over 14+ years I've built web UI for agencies, enterprises, and global services, led teams in Korea and Vietnam, and kept asking one question: *"How could this code be better?"* I enjoy sharing what I learn along the way.

- **Core**: HTML/CSS/JavaScript — the web platform itself
- **Extended with**: TypeScript, React, Next.js, Vue.js, Nuxt.js
- **Working at**: Hivelab as Interactive UI Development Team Head / Lead UI Developer
- **Side lab**: [playgrounder.dev](https://www.playgrounder.dev) — turning ideas into web services
- **Currently exploring**: Web performance, accessibility, modern CSS, and AI-assisted development
- **For fun**: Building small games with Unity
